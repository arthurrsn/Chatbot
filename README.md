# Chatbot

**Nome:** Vivenda Chatbot
**Status:** Ativo
**Descrição:**
Chatbot que irá proporcionar mais tempo, logistica e visibilidade, realizando todo o primeiro atendimento ao cliente. Sistema integrado com whatsapp e google AI pro para ser robusto e eficiente.
